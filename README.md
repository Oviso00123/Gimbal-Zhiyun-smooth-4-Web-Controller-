# Gimbal-Zhiyun-smooth-4-Web-Controller-
This is a Web Site to control a **Zhiyun Smooth 4** gimbal directly from any Web Browser (smartphone or PC) using Bluetooth (Web BLE API).

📌 What is this project?
This is a single-file Web App to control a **Zhiyun Smooth 4** gimbal directly from any Web Browser (smartphone or PC) using Bluetooth (Web BLE API).

It's built for a simple problem: keep your main phone on the gimbal for calls or videos, and use a second device as a smart remote control.

### 🚀 Main Features
* 🎮 **Touch Joystick:** Easy control for Pan and Tilt using touch or keyboard (WASD).
* 🔋 **Real Battery Fix:** Calibrated battery percentage with a warning banner below 20%.
* 🪄 **Air Mouse / Motion Steering:** Control the gimbal by simply tilting your controller phone!
* 🖐️ **Gesture Control (MediaPipe):** Use hand gestures (fist, open palm, ok) to trigger actions or stop the gimbal.
* 🎬 **Motion Routines & Speed Presets:** Record custom movements, save them with names/emojis, and play them back anytime.
* 📍 **Quick Save Positions:** Save your favorite camera angles with one tap.
* 🎙️ **Voice Commands:** Control the gimbal using simple voice commands.
* 🛡️ **Kill Switch & Touch Lock:** Red emergency button to stop all motors immediately.
* 📱 **Mobile First & PWA:** Fully responsive for phone screens with keep-awake support.

### 🛠️ How to use it?
1. Open `index.html` in a modern web browser (Chrome, Edge or Brave).
2. Turn on Bluetooth on your device.
3. Click **"Connect Zhiyun"** and choose your Smooth 4 gimbal.
4. Enjoy your smart web controller!
